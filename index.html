الإعدادات

هذه نسخة GitHub Pages ثابتة. القيم أدناه تُحفظ في متصفحك فقط عبر Local Storage ولا تُرفع إلى GitHub. الماسح لا يحتاج مفتاح Binance؛ بيانات السوق المستخدمة عامة. مفاتيح Binance تبقى داخل بوت Futures فقط عند إضافة التنفيذ لاحقًا. هنا يوجد مكان مستقل لبوت Futures ومكان مستقل لبوت Spot.

زر إيقاف الماسح يوقف البحث عن إشارات جديدة، لكن متابعة أي صفقة/إشارة مفتوحة تستمر حتى TP3 أو SL حتى لا تضيع النتيجة.

المنطق المعتمد

الدخول 5m15m30m
التأكيد فقط 1h4h12h1d

فريمات التأكيد لا يجب أن تتوافق كلها. يتم تقييم EMA20/50/200، الدعم والمقاومة، Breakout/Breakdown، Retest، الدعم/المقاومة المكسورة، Oversold/Overbought، ضغط Taker أثناء تكوّن الشمعة، حجم التداول، Rejection، Trend Retest وLate Entry. Futures يضيف Funding وOpen Interest وTaker Ratio وOrder Book كعوامل إضافية.

Spot: تُقفل العملة نفسها بعد إرسالها حتى TP3 أو SL. Futures: توجد إشارة نشطة واحدة فقط للنظام كله حتى TP3 أو SL.

التتبع يستخدم Binance aggTrade لحظيًا. إذا انقطع الاتصال أو جمّد Safari الصفحة، يتم فحص تداولات aggTrade التاريخية عند الرجوع بالترتيب الزمني حتى لا تضيع لمسة TP أو SL. حالة الصفقة تُغلق أولًا ثم تُرسل رسالة Telegram، وإذا فشل Telegram يعاد إرسال النتيجة لاحقًا.
